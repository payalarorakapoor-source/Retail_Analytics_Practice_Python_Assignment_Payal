# Retail_Analytics_Practice_Python_Assignment_Payal
This Python project analyzes retail analytics data that I read from Superstore csv file and creates easy-to-read charts
## 📖 Overview
This project is written in Python and is designed to be simple, clear, and beginner-friendly.  
It can be used for learning, solving practical problems.
## ✨ Features
- Easy to understand code
- Step-by-step workflow
- Uses Python libraries like Pandas , Matplotlib , Seaborn for data handling and visualization
- Popular and advance  libraries for visualisation. Matplotlib is foundation and important  and used for visualization 
numpy, pandas, matplotlib, seaborn, plotly
Matplotlib is used for Visualization, creating plots
- Can be customized with your own data
## ⚙️ Requirements
Make sure you have:
- Python 3.x installed
- Required libraries (example: pandas, numpy, matplotlib, Seaborn )
   In this project We will  Analyze and Visualize below mentioned Points
  1. Profit margins by category and sub-category
  2. Sales and profit by state
  3. Average Sales and Profit by Discount
  4. Top 10 Loss-Making Products
  5. Average delivery time by ship mode
  6. Profit by Shipping Mode
  7.Shipping Performance by Region
  8. Average Order Value by Segment
  9. Top 10 Profitable Customers
  10. Repeat Customer Behavior
  11. Monthly sales, profit, and discount trends
  12. Peak Sales Months
  13. Sub-Category Sales per Unit
  14. Sample Product Combinations
